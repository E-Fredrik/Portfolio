# Personal Portfolio

A modern, animated personal portfolio website built with Next.js, React, and Tailwind CSS. The site features smooth interactions and animations powered by GSAP.

## 🚀 Technologies Used

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Library:** [React](https://react.dev/) 19 & React Compiler
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [GSAP](https://gsap.com/) (GreenSock Animation Platform)
- **Language:** [TypeScript](https://www.typescriptlang.org/)

## ⚙️ Features

- 🎨 **Modern Design:** Clean UI using Tailwind CSS.
- ✨ **Interactive Animations:** Features GSAP animations, including:
  - Custom cursor reveals (`CursorReveal`).
  - Staggered navigation menus (`StaggeredMenu`).
  - Smooth page transitions and loading screens.
- 📱 **Responsive:** Fully responsive design that works on mobile, tablet, and desktop devices.
- ⚡ **Optimized:** Fast performance thanks to Next.js App Router and React Compiler.

## 🛠️ Getting Started

First, install the dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the portfolio in action.

## 📂 Project Structure

- `src/app/` - Next.js App Router endpoints and primary layouts.
- `src/app/components/` - Reusable UI elements (`Hero`, `Projects`, `TechStack`, `Timeline`, etc.).
- `public/assets/images/` - Static assets and images.
